# TechPulse AI Bootcamp — local landing-page clone

A responsive static recreation based on the supplied screenshot and the publicly visible TechPulse page content.

## Run

Open `index.html` directly, or serve the folder with any static server.

Example:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
